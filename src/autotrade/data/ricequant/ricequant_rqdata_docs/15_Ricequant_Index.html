get_price - 获取米筐特色指数历史行情数据 ​

python
get_price(order_book_ids, start_date='2022-01-04', end_date='2023-01-04', frequency='1d', fields=None, market='cn', expect_df=True,time_slice=None)

获取米筐特色指数的历史行情数据，支持周、日、分钟和 tick 级别查询。支持指数可参考 米筐特色指数列表，例如米筐小市值概念指数、米筐可转债等权指数、米筐微盘股指数等特色指数行情。

米筐小市值概念指数 ​

   随着注册制的正式落地，A 股股票数量已经超过 5000 只，其中小市值股票也在这几年引起了市场的广泛关注。米筐小市值概念指数旨在为投资者提供反映 A 股市场小市值风格特征的代表指数，既可作为被动投资标的，也可作为量化投资策略的业绩比较基准。用户可通过米筐 RQData 金融数据 API 获取指数历史及实时行情数据，亦可在米筐 RQAMS 资产管理系统中选择米筐小市值指数作为业绩基准，对风格匹配的产品或投资组合进行深度分析。

指数编制规则 ​

  • 指数名称：米筐小市值概念指数
  • 英文名称：Ricequant Small Market Value Concept Index
  • 指数代码：866002.RI
  • 指数类型：股票类
  • 指数基日：2015-12-31
  • 指数基点：1000
  • 上线日期：2023-08-11
  • 加权方式：等权重
  • 收益处理方式：价格指数
  • 指数简介：“小市值”指市值小于 100 亿的公司，每月底调样
  • 样本空间：上海、深圳证券交易所中上市交易的全部 A 股股票

  • 指数名称：米筐小市值概念全收益指数
  • 英文名称：Ricequant Small Market Value Concept Total Return Index
  • 指数代码：866001.RI
  • 指数类型：股票类
  • 指数基日：2015-12-31
  • 指数基点：1000
  • 上线日期：2023-08-11
  • 加权方式：等权重
  • 收益处理方式：全收益指数
  • 指数简介：“小市值”指市值小于 100 亿的公司，每月底调样
  • 样本空间：上海、深圳证券交易所中上市交易的全部 A 股股票

   米筐小市值概念指数与米筐小市值概念全收益指数采用“等权”的编制方法，每日平衡，即每一只成分股每日对于指数收益率的影响是等权的。不同的是，米筐小市值概念指数为价格指数，不对成分股分红进行调整，任由其价格自行回落，米筐小市值概念全收益指数则考虑到成分股的权益类事件以进行调整，例如对股票分红、拆分、送股等权益类事件进行复权。

米筐可转债等权指数 ​

米筐股指期权波动率指数（VIX） ​

   波动性指数（VIX）作为一个实时市场指标，反映了市场对未来 30 日内波动性的预期。在投资决策过程中，投资者常利用 VIX 指数来评估市场风险程度、恐慌情绪或压力状况。该指数所用期权到期月份的选取规则如下：若查询日期早于当月期权到期日，则以查询日所在月份为期权到期月；若查询日期晚于当月期权到期日，则以次月为期权到期月。

  • 指数单位：年化百分比

  • 计算方式：

    VIX=100×{T1σ12[NT2−NT30NT2−NT1]+T2σ22[NT30−NT1NT2−NT1]}×NT365NT30

    其中，NT1 表示当前时间距离当期合约结束的分钟数（本月到期），NT2 表示当前时间距离下期合约结束的分钟数（次月到期），NT30 表示 30 天的分钟数，NT365 表示本年分钟数，σ12 表示当期波动率，σ22 表示下期波动率。
